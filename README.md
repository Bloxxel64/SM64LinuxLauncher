# SM64LinuxLauncher

## About

SM64LinuxLauncher is a tool for downloading, compiling, updating, launching, and even installing the various versions of the Super Mario 64 PC Port.

Linux has been lacking when it comes to utilities for this, while Windows has tools like SM64PCBuilder2, Linux... not so much, this tool aims to remedy that and make the game more accessible.
